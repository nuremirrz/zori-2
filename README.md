# Зарина Жанатаева — сайт художницы

Одностраничный сайт современной художницы: интерьерные картины, Алматы.
Чистые HTML / CSS / JS, без сборки и зависимостей — открывается двойным кликом
по `index.html`.

## Структура

```
zori/
├── index.html
├── BRIEF.md            бриф для клиента: что нужно собрать
├── CONTENT.md          полученные материалы и открытые вопросы
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── img/
        ├── works/      картины: -front, -detail, -interior
        ├── studio/     работы в пространстве, первый экран
        └── author/     портрет и процесс
```

## Как запустить

Откройте `index.html` в браузере. Для локального сервера (нужен, если будете
добавлять формы): `python3 -m http.server 8000` в папке проекта.

Покупка и доставка → Контакты.

## Дизайн-система

Все цвета и шрифты — в переменных в начале `assets/css/style.css`.

**Палитра.** Почти белая с тёплым подтоном. Акцентного цвета в интерфейсе нет
намеренно: цвет на странице дают сами работы. Единственное исключение —
приглушённый красный `--accent`, он используется только для точки статуса
«доступна» и для пометок-заглушек.

**Шрифты.**
- `Cormorant Garamond` — заголовки и названия работ. Проверено: содержит
  и латиницу с диакритикой (`ä ş ı`), и казахскую кириллицу (`ә ү қ ң ө ұ і ғ һ`),
  поэтому название «Äiel küşı» набирается в любом написании.
- `Golos Text` — основной текст. Cormorant слишком тонкий для мелких размеров.
- `JetBrains Mono` — характеристики работ, подписи, навигация. Моноширинный
  шрифт под размеры и техники читается как музейная этикетка.

## Картинки

Каждое фото лежит в двух размерах: `имя.jpg` (1600 px по длинной стороне) и
`имя-900.jpg` — подключены через `srcset`, браузер сам берёт нужный.
Все, кроме первого экрана, грузятся лениво.

Исходники (HEIC и JPEG с телефона) лежат вне репозитория, в `~/Desktop/emirlan/zori-img`.
Пересобрать вариант можно так:

```bash
sips -s format jpeg -s formatOptions 68 -Z 1600 исходник.HEIC --out assets/img/works/имя.jpg
```

## Заглушки

Места, где ещё нет текста от автора, помечены на странице классами `.tbd`
и `.tbd-inline` — пунктирная рамка и красная подпись, что именно нужно.
Список всех открытых вопросов — в `CONTENT.md`.
