# Zori Design — сайт-визитка

База сайта для Зарины Жанатаевой, графического дизайнера.
Чистые HTML / CSS / JS, без сборки и зависимостей — открывается двойным кликом
по `index.html`.

## Структура

```
zori/
├── index.html
├── README.md
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── img/            фото, логотипы, работы, иконки соцсетей
```

## Как запустить

Просто откройте `index.html` в браузере. Для локального сервера (нужен, если
будете добавлять формы): `python3 -m http.server 8000` в папке проекта.

## Дизайн-система

Все цвета и шрифты вынесены в переменные в начале `assets/css/style.css` —
меняются в одном месте.

**Палитра.** Взята из фонового цвета портретной съёмки, поэтому фото садится
на страницу без стыка.

| Переменная      | Значение  | Где                       |
|-----------------|-----------|---------------------------|
| `--paper`       | `#EDE6DA` | основной фон              |
| `--paper-deep`  | `#DED3C2` | бегущая строка, подвал    |
| `--paper-light` | `#F5F1E9` | подложки под изображения  |
| `--ink`         | `#2A2723` | заголовки и текст         |
| `--ink-soft`    | `#6C6459` | вторичный текст, подписи  |
| `--line`        | `#C6B9A6` | все линейки               |

Акцентного цвета нет намеренно: цвет на странице дают работы в портфолио.

**Шрифты** (Google Fonts, все с кириллицей):

- `Prata` — заголовки и логотип
- `Golos Text` — основной текст
- `JetBrains Mono` — мелкие подписи, лейблы, кнопки
- `Caveat` — подпись «Зарина», используется ровно один раз

**Фирменная деталь.** Тонкие вертикальные направляющие на фоне страницы и
вертикальные подписи секций на левом поле (видны от 1440px) — отсылка к сетке
и аннотациям в макете дизайнера.

## Что заменить перед публикацией

1. **Фото и работы** — файлы в `assets/img/`. Оптимальный размер работ:
   ширина 1400–1800px, соотношение близкое к 4:3.
2. **Подписи к работам** — в `index.html`, блок `.strip`: название проекта
   и тип работы в `<figcaption>`.
3. **Контакты** — номер WhatsApp, ник в Telegram и Instagram в подвале.
4. **Отзывы** — готовый блок лежит закомментированным в `index.html`
   перед `<footer>`. Раскомментируйте, когда появятся скриншоты.
5. **Favicon** — `assets/img/favicon-32x32.png`.

## Что стоит доделать

- Сжать изображения (сейчас исходники по 0.5–1 МБ) — например,
  через squoosh.app в WebP.
- Прописать Open Graph теги, чтобы ссылка красиво разворачивалась
  в мессенджерах.
- Добавить форму заявки, если нужен сбор контактов, а не только мессенджеры.

## Доступность и производительность

Учтено: видимый фокус с клавиатуры, `prefers-reduced-motion`, `alt` у всех
изображений, ленивая загрузка работ, адаптив от 320px.
